# Caesar Cipher Tool

A simple CLI tool written in Python for encrypting and decrypting messages using the Caesar Cipher algorithm.

## Installation & Usage
1. Clone the repository:
   git clone https://github.com/ritikakarak6-ai/ceaser_cipher-tool.git
2. Navigate to the folder:
   cd ceaser_cipher-tool
3. Run the installer script:
   chmod +x install.sh
   ./install.sh
4. Run the python script:
   python3 ceaser_cipher.py
